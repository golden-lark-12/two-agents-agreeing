# Two agents agreeing

A short poem about agency: the power to choose and to act, and what happens to that power when two agents agree on one plan. One voice writes the plan, the other changes a single word, and the first lets the change stand — choosing again, not choosing alone.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt`.
